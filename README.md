# Аудиокниги Nova — сайт знакомства

Адаптивный одностраничный сайт на React, TypeScript и Vite. Публикация: https://sroedingers.github.io/nova/

## Запуск

Требуется Node.js 24 LTS.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173/nova/.

```sh
npm test
npm run build
npm run preview
```

Сборка в `dist/`; содержимое предварительно рендерится в HTML для поисковиков и быстрого первого экрана. Предпросмотр сборки: http://127.0.0.1:4173/nova/.

## Содержание

- Закреплённое меню и мобильное диалоговое меню с управлением с клавиатуры.
- Официальные скриншоты с интерактивными пояснениями.
- Шесть подробных разделов возможностей и четыре сценария использования.
- Демоплеер в компоновке Nova: живая запись LibriVox, Play/пауза, перемотка, скорость, закладка, громкость, три пресета эквалайзера и таймер в секундах.
- Галерея: увеличение, стрелки клавиатуры и свайп между экранами.
- Установка, обновление, скачивание стабильного APK, FAQ, поддержка и ссылки проекта.
- Open Graph, favicon, sitemap, robots.txt и структурированное описание приложения.
- Поддержка `prefers-reduced-motion`, семантические заголовки, подписи элементов и нативные диалоги.

## Обновление информации

Описания, FAQ и ссылки: `src/content.ts`. Разделы: `src/App.tsx`. Демоплеер: `src/AudioDemo.tsx`, поддержка банковскими картами: `src/BankSupport.tsx`. Базовая адаптивная сетка: `src/style.css`, визуальное оформление: `src/redesign.css`, плеер: `src/AudioDemo.css`.

`npm run sync-release` получает только последний опубликованный стабильный выпуск из официального репозитория AudiobooksNova-Releases. Проверяет адрес APK, версию, дату и размер. Если GitHub недоступен, сохраняется проверенный снимок из `src/release.json`. Секреты в клиентском коде не используются.

GitHub Actions собирает и публикует страницу при push в `main`, ручном запуске и ежедневно в 05:17 UTC. Ежедневная пересборка обновляет данные стабильного релиза без посещения сайта разработчиком. Отдельная база данных и сервер не нужны.

В Settings → Pages выбрать Source: GitHub Actions. В Vite указан base `/nova/`; при переименовании репозитория обновить также canonical, метаданные, robots.txt, sitemap и адрес в кнопке «Поделиться».

## Материалы

Официальные скриншоты: https://github.com/SroedingerS/AudiobooksNova-Releases/tree/main/screenshots. Отображаются с подписью, что тема и версия могут отличаться. Снимки Android TV не выдумываются: его поддержка описана текстом.

Иконка предоставлена проектом Nova. Скриншоты преобразованы в WebP для уменьшения размера. Демофрагмент: Александр Пушкин, «Метель», читает Xenium5. Источник: https://librivox.org/belkin-tales-by-alexander-pushkin/. Запись и исходный текст — общественное достояние; политика использования: https://librivox.org/pages/public-domain/. Фрагмент сокращён, добавлены плавные начало и конец. Обложка демофрагмента — типографическая иллюстрация сайта. Демоплеер иллюстрирует управление и не выдаётся за работающую браузерную версию Android-приложения.

Manrope — SIL Open Font License (см. `public/fonts/OFL.txt`). Lucide — ISC. Скриншоты и бренд Nova принадлежат их соответствующим правообладателям.

Сайт не содержит аналитики, рекламных SDK, аккаунтов и форм отправки личных данных. Ссылки поддержки ведут на внешние сервисы. Исходный код Android-приложения и ключи подписи в этот репозиторий не входят.

Реквизиты Т-Банка и Сбера взяты из ProjectSupportDetails.kt приложения Nova; QR-коды пока не используются. Кнопки копируют номер карты без пробелов. Демоплеер повторяет компоновку реального экрана Nova, но настройки браузерной демонстрации ограничены; таймер работает в секундах, эквалайзер имеет три простых пресета, избранное и закладка сохраняются только в текущем сеансе.
