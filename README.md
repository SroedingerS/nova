# Аудиокниги Nova — сайт и инструкция

## Локальный вариант с инструкцией · 26 октября 2026

Добавлен отдельный адрес `/nova/guide/`: 42 практические статьи, 131 названий настроек,
поиск по словам и синонимам, фильтр разделов, связанные статьи и ссылки на конкретную
подсказку. Тексты предварительно рендерятся в HTML. На главной — четыре настоящих

открыть `portable-preview/index.html` или `portable-preview/guide/index.html`.

`src/guide-settings.json`; интерфейс: `src/Guide.tsx`; оформление: `src/Guide.css`;
блок читалки: `src/ReaderShowcase.tsx`; снимки: `public/reader/`.
Источники, ограничения проверки и правила обновления: `GUIDE-CONTENT.md`.

Вариант подготовлен и проверен в отдельной локальной копии. Публикация выполняется
существующим процессом GitHub Pages из ветки `main`.

Адаптивный сайт с отдельной инструкцией на React, TypeScript и Vite. Публикация: https://sroedingers.github.io/nova/

## Запуск

Требуется Node.js 24 LTS.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173/nova/.

```sh
npm test
npm run build
npm run preview
```

Сборка в `dist/`; содержимое предварительно рендерится в HTML для поисковиков и быстрого первого экрана. Предпросмотр сборки: http://127.0.0.1:4173/nova/.

## Содержание

- Закреплённое меню и мобильное диалоговое меню с управлением с клавиатуры.
- Первый экран в тёплом книжном оформлении: переключение каталога, библиотеки и плеера, настоящие фрагменты интерфейса и небольшой наклон превью при движении указателя.
- При прокрутке на ПК закреплённый экран меняется вместе с описанием выбора книги, офлайн-загрузок и таймера. На телефонах экраны расположены рядом с текстом своих разделов. Без JavaScript остаётся обычная последовательность всех экранов.
- Демоплеер в компоновке Nova: живая запись LibriVox, Play/пауза, перемотка, скорость, закладка, громкость, три пресета эквалайзера и таймер в секундах.
- Галерея: кнопки прокрутки, увеличение, стрелки клавиатуры и свайп между экранами.
- Установка, обновление, скачивание стабильного APK, FAQ, поддержка и ссылки проекта.
- Nova 3.0: описание текстовой читалки, поддерживаемых форматов, OPDS и системного чтения вслух; инструкция, где найти вкладку и как отключить её. DjVu, DRM и озвучивание PDF-сканов не обещаются. Старые аудиоскриншоты не выдаются за экраны читалки.
- Поисковый заголовок и описание, canonical, Open Graph, Twitter Card, favicon, sitemap и структурированное описание приложения с актуальным релизом.
- Визуализация настоящего звука демофрагмента через Web Audio AnalyserNode; во время паузы показана спокойная линия. Звук включается только после нажатия Play.
- Индикатор прогресса страницы и мягкое появление разделов. Поддержка `prefers-reduced-motion`, семантические заголовки, подписи элементов и нативные диалоги.

## Обновление информации

Описания, FAQ и ссылки: `src/content.ts`. Разделы: `src/App.tsx`. Демоплеер: `src/AudioDemo.tsx`, поддержка банковскими картами: `src/BankSupport.tsx`. Основное оформление: `src/site.css`; первый экран, движение и сцены: `src/HeroExperience.tsx` и `src/Experience.css`; плеер: `src/AudioDemo.css`; визуализация звука: `src/SoundVisual.tsx`.

`npm run sync-release` получает только последний опубликованный стабильный выпуск из официального репозитория AudiobooksNova-Releases. Проверяет адрес APK, версию, дату и размер. Если GitHub недоступен, сохраняется проверенный снимок из `src/release.json`. Секреты в клиентском коде не используются.

GitHub Actions собирает и публикует страницу при push в `main`, ручном запуске и ежедневно в 05:17 UTC. Ежедневная пересборка обновляет данные стабильного релиза без посещения сайта разработчиком. Отдельная база данных и сервер не нужны.

В Settings → Pages выбрать Source: GitHub Actions. В Vite указан base `/nova/`; при переименовании репозитория обновить также canonical, метаданные, sitemap и адрес в кнопке «Поделиться».

## Поисковая индексация

GitHub Pages публикует обычный общедоступный сайт, который может индексироваться поисковиками. Основной адрес: `https://sroedingers.github.io/nova/`. Страница отдаёт готовый HTML с текстом, заголовками и ссылками ещё до выполнения JavaScript. Разделы с `#` — части одной страницы, а не самостоятельные адреса в sitemap.

При сборке разметка `SoftwareApplication` получает версию, размер APK, ссылку для скачивания и описание выпуска из проверенного `src/release.json`. Разработчик указан как Schroedinger's Cat. Рейтинги и отзывы в разметке не выдумываются; расширенный результат Google для приложения не обещается. Страница ошибки содержит `noindex`, главная — `index, follow`.

Карта сайта: `https://sroedingers.github.io/nova/sitemap.xml`. Для проверки появления в Google добавьте URL-prefix ресурс `https://sroedingers.github.io/nova/` в Google Search Console, подтвердите права через предоставленный сервисом HTML-файл или метатег, отправьте `sitemap.xml` и запросите индексирование главной через проверку URL. Подтверждающие файлы и значения должны быть получены из аккаунта владельца; их нет в репозитории. Индексация и позиции не гарантируются.

`robots.txt` учитывается только в корне хоста — `https://sroedingers.github.io/robots.txt`. Файл внутри `/nova/` не является настройкой для этого хоста, поэтому из сборки он удалён. На момент проверки корневой адрес возвращает 404, что не запрещает обход сайта. Если владелец впоследствии настроит корневой robots.txt через сайт аккаунта GitHub Pages, в нём можно указать адрес карты сайта. Для Яндекса используйте Вебмастер; подтверждение владения хостом может потребовать доступа к корневому сайту аккаунта.
