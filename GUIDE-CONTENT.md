# Инструкция Nova: содержание и обновление

Подготовлено 26.10.2026. Базовая версия — опубликованная Stable 3.0.1h.
Это сайт и справочник, не продолжение аудита приложения и не изменение его кода.

## Откуда взяты сведения

- Исходный сайт: репозиторий SroedingerS/nova, база cfe2c1b. Сохранены палитра,
  шрифты, основные секции, демоплеер и GitHub Pages с base `/nova/`.
- Версия и APK: официальный GitHub Releases, обновлены существующим sync-release.
- Снимки: собственный AVD Android 13, опубликованный APK AudiobooksNova-3.0.1h.apk,
  SHA-256 5e0799a0f58c89fb903311a6e6da39e20a3bf89e98628348471582da8013f926.
- Названия настроек и группы: SettingsSearch.kt из исходников Nova; общие функции
  сверены с текущими материалами сайта, исходниками и описанием выпуска 3.0.1h.
- Читалка: ReaderScreen.kt, ReaderLibraryScreen.kt, ReaderShelfDialogs.kt;
  меню и действия импорта, страницы, оглавления, закладок проверены в эмуляторе.
- Пользовательская обложка: MainActivity.kt, действие «Изменить обложку».
- Виджеты: widget/NovaPlaybackWidget.kt и манифест Android.
- Новые индивидуальные подписки из ещё изменяемого кода не включены в навигатор
  как уже выпущенная возможность. Статья о подписках не обещает конкретные новые
  переключатели, которых может не быть в установленной версии.

## Покрытие

41 статья в 6 разделах: первые шаги; прослушивание; читалка; библиотека;
персонализация; помощь. Навигатор содержит 128 уникальных названий настроек с
путями и переходами к объясняющей статье. Указаны ограничения ТВ/телефона, когда
они есть. Это индекс известных пунктов, а не заявление о проверке каждой
комбинации настроек на каждом устройстве.

Детально описаны поиск/каталог/издания, плеер/звук/таймер/гарнитура, офлайн и очередь,
радио/Musify, импорт текста, оформление, оглавление, заметки, TTS и PDF,
OPDS, связь текста и аудио, перенос, полки/обложки/аудиозакладки, локальные и сетевые
файлы, очистка, резервные копии/синхронизация/уведомления, виджеты, e-ink/ТВ/планшет,
производительность/выход, источники/фон/диагностика/обновления.

## Изображения

`public/reader/reading.png`, `appearance.png`, `contents.png`, `bookmarks.png` —
неизменённые снимки через adb screencap, 1080×2160. Веб-страница добавляет рамку,
фон, тень и подпись средствами CSS; интерфейс на снимках не перерисовывается.
Использована специально написанная демонстрационная книга «Дом у тихой воды»
(Демо Nova); её текст не выдан за произведение другого автора.

В исходном эмуляторе нет TTS-движка: работа озвучивания не заявлена как проверенная
и её скриншот не имитируется. В статье объясняется необходимость установленного
движка. Старые снимки аудиоразделов оставлены с оговоркой о различиях оформления.

## Проверка и границы

- TypeScript и production-сборка обеих страниц; HTML доступен до запуска JS.
- Тесты проверяют связанные ссылки, уникальность настроек, реальные файлы снимков,
  русский поиск, пустой результат, содержимое и метаданные собранной инструкции.
- В браузере проверяются переходы из настройки к статье, фильтры, ссылки,
  увеличение изображений и адаптивные размеры. Локальный итог записан в
  review/QA.md (не включается в публикацию).
- Статьи не заменяют тестирование Android: облако, реальные гарнитуры, ТВ и e-ink
  в рамках работы над сайтом на физических устройствах не проверялись.
- Исходники приложения и другой чат в рамках подготовки сайта не изменялись.
  Публикация сайта выполняется через существующий процесс GitHub Pages.

## Как поддерживать

1. Обновить baseline версии после выхода Stable, не по незавершённому коду.
2. Сопоставить изменённые пункты с guide-settings.json и связанными статьями.
3. Для изменившегося экрана снять новый кадр из соответствующего APK.
4. Проверить поиск, связанные ссылки и мобильную компоновку, выполнить сборку и тесты.
5. Публиковать обычный dist/ через существующий процесс GitHub Pages после решения
   владельца сайта. Локальный portable-preview предназначен только для просмотра.
